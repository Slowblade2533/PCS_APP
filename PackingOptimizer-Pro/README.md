# Packing Optimizer Pro

ระบบคำนวณการบรรจุสินค้าใส่กล่องพัสดุแบบ Professional สำหรับคลังสินค้าและ E-Commerce พัฒนาด้วย Vanilla HTML, CSS และ JavaScript เพื่อการทำงานที่รวดเร็ว ปลอดภัย และออฟไลน์ 100%

## คุณสมบัติเด่น (Features)
- **Offline 100%**: ไม่ต้องใช้ Node.js หรืออินเทอร์เน็ต สามารถเปิด `index.html` ด้วยการดับเบิลคลิกเพื่อใช้งานได้ทันที
- **Responsive Design**: การออกแบบที่สวยงาม ทันสมัย รองรับทั้ง Dark Mode และ Light Mode รวมถึงการแสดงผลบนอุปกรณ์พกพา
- **Multi-SKU & Multi-Quantity**: คำนวณการจัดเรียงสินค้าหลายชนิด หลายขนาด และหลายจำนวนพร้อมกัน
- **Bubble & Foam Padding**: มีระบบคำนวณพื้นที่เผื่อแผ่นกันกระแทกอย่างแม่นยำ
- **Exporting Options**: ส่งออกข้อมูลผลลัพธ์เป็นไฟล์ CSV, JSON หรือสั่งพิมพ์ใบจัดส่งสินค้า (Packing Slip) ได้ทันที

## โครงสร้างโฟลเดอร์ (Architecture)
- `index.html`: ไฟล์หลักของแอปพลิเคชัน
- `css/`: ไฟล์สไตล์ชีทสำหรับจัดหน้าและธีมสี
- `js/`: โค้ดเชื่อมต่อระบบหลัก (Bootstrap & App Coordinator)
- `database/`: ตัวจัดการข้อมูล CRUD และ Persistence (LocalStorage)
- `engine/`: สมองกลคำนวณทิศทาง การทับซ้อน และการทำลายนิ้วมือกล่องว่าง (Bin Packing Algorithms)
- `renderer/`: โมดูลสำหรับวาดภาพจำลองการแพ็คกล่องแบบ 2D/3D Canvas
- `ui/`: ส่วนติดต่อผู้ใช้หลัก
- `utils/`: ฟังก์ชันเสริมความปลอดภัย คำนวณคณิตศาสตร์ และส่งออกไฟล์
